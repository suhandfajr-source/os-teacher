# AI Teacher Assistant — Development Handoff

Copy the contents of this package into the root of your empty Antigravity workspace named **Ai Teacher Assistant**.

Recommended structure after copy:

```text
Ai Teacher Assistant/
├── MASTER_CONTEXT.md
├── docs/
│   ├── product/
│   │   └── <Stage 01–09 product specification files>
│   ├── architecture/
│   │   └── TECHNICAL_ARCHITECTURE.md
│   └── development/
│       └── DEV_STAGE_00_PROJECT_FOUNDATION.md
├── .agents/
│   └── rules/
│       └── project-rules.md
└── FIRST_ANTIGRAVITY_PROMPT.md
```

## Before Coding

1. Put your Stage 01–09 product documents inside `docs/product/`.
2. Copy the architecture, rules, master context, and Dev Stage 00 files from this package.
3. Open `FIRST_ANTIGRAVITY_PROMPT.md`.
4. Paste that prompt into Antigravity.
5. Let Antigravity implement only Development Stage 00.
6. Do not ask it to continue to Stage 01 until Stage 00 has been reviewed and marked PASS.
