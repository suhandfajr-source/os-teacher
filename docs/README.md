# Peta Dokumentasi

> Satu halaman ini adalah titik masuk semua dokumentasi. Nyasar? Mulai dari sini.

## Ke Mana Mencari

| Mau cari... | Buka |
|---|---|
| Cara kerja sistem secara teknis | `architecture/` |
| Fitur produk, blueprint, product knowledge | `product/` |
| UI/UX, design system, spesifikasi tampilan | `design/` |
| Rencana build per stage, checklist rilis, playbook | `development/` |
| Riwayat analisis & dokumen lama (ARSIP) | `reports/` |
| Preview visual & showcase (HTML/PNG/PDF) | `presentations/` |
| Logo & aset brand | `brand/` |

## Rincian Penting

- **`development/stages/`** — urutan build `DEV_STAGE_00` → `DEV_STAGE_11` (+ revisi & addendum)
- **`development/guides/`** — panduan kerja (hemat token, dll.)
- **`development/folder-blueprint.md`** — blueprint reorganisasi docs & folderisasi `src/` (masih berjalan: Tahap B menunggu)
- **`presentations/samples/`** — contoh deck PPTX & slide (material fitur PPT generator)
- **`product/PRODUCT_KNOWLEDGE_V2.*`** — versi mutakhir; V1 ada di `reports/` sebagai arsip
- Root repo: `MASTER_CONTEXT.md` (konteks utama project) & `README_START_HERE.md`

## Status Dokumen

| Status | Folder | Aturan |
|---|---|---|
| 🟢 Hidup | `architecture/`, `development/`, `product/`, `design/` | Boleh & harus di-update |
| 💤 Arsip | `reports/` | Jangan di-update, jangan dihapus — ini sejarah keputusan |
| 🎨 Pajangan | `presentations/` | Turunan visual, bukan sumber kebenaran |

## Konvensi

1. File baru: huruf kecil + tanda hubung (`release-checklist.md`)
2. Markdown = sumber kebenaran; HTML/PDF = turunan untuk pajangan
3. Dokumen baru masuk laci sesuai tabel di atas — ragu? Lihat kolom "Mau cari..."
