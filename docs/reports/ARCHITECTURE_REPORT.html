Aplikasi ini adalah monolit modular: satu codebase Next.js dengan batas modul internal yang tegas, satu database relasional (PostgreSQL) sebagai single source of truth, dan integrasi AI yang selalu lewat lapisan abstraksi AI Service — tidak pernah dipanggil langsung dari komponen UI. Prinsip utamanya:

AI Assists, Teacher Decides — AI men-generate dan menjelaskan, guru yang memutuskan.

2Gaya Arsitektur — Modular Monolith

Satu aplikasi, satu database relasional, satu codebase — dengan batas modul yang kuat secara internal. Tidak ada microservices; infrastruktur kompleks (Kafka, Redis cluster, Kubernetes, vector DB) sengaja tidak dipakai di V1 dan hanya ditambahkan bila ada kebutuhan produksi nyata.

AI TEACHER ASSISTANT ├── auth / student-auth ├── quiz + cbt-live (ujian online) ├── teachers / schools ├── reporting / templates ├── classes / students ├── agent (AI chat streaming) ├── teaching / schedule ├── ai (AI Service abstraction) ├── attendance ├── imports / exports ├── assignments / assessment ├── storage (S3-compatible) ├── scores / monitoring ├── notifications └── approvals / admin / system-settings / student-portal

Aturan batas modul

  • Logika bisnis tidak boleh menempel langsung di komponen UI.
  • Modul yang tidak berhubungan tidak boleh saling couple langsung.
  • Operasi lintas modul harus lewat service eksplisit; helper bersama di lapisan lib.
  • Tidak boleh ada sumber kebenaran ganda (duplicate source of truth).

5Arsitektur Database

PostgreSQL adalah sumber kebenaran. Hierarki intinya berbasis School Workspace (multi-sekolah):

School Workspace │ ├── AcademicPeriod ── Subject ── Class │ │ └── Student ──── ClassStudent Membership │ Teacher ── TeacherSchoolMembership │ TeachingContext (sesi mengajar) │ Assessment │ Score │ Remedial

Prinsip data

  • Data relasional dulu; data aktivitas mentah sebelum ringkasan; statistik bersifat derived.
  • Rencana mengajar ≠ pelaksanaan mengajar (dipisah).
  • Laporan adalah output, bukan sumber kebenaran.
  • Konteks akademik opsional — tidak boleh menghalangi alur kerja harian.
  • Riwayat record penting dipertahankan.
  • Semua perubahan schema lewat Prisma migrations (33 sudah ter-apply, terverifikasi verify:migrations).

7Arsitektur AI

AI tidak pernah dipanggil langsung dari komponen UI. Semua lewat abstraksi:

UI ──► AI Service ──► AI Provider ──► Gemini / GLM Kemampuan: generateLessonPlan · generateMaterial · generateQuestions · generateAnswerKey · generateWorksheet · generateRPP · generateSummary · generateNarrativeInsight · streaming chat (/api/agent/chat)

Alur output AI selalu:

GenerateValidasi (Zod)PreviewReview GuruEditSimpan / Pakai / Unduh

AI BOLEH

  • Generate konten (materi, soal, RPP, presentasi)
  • Ringkas & menjelaskan
  • Rekomendasi & insight naratif

AI TIDAK BOLEH (V1)

  • Mengoreksi lembar jawaban siswa / OCR grading
  • Menentukan nilai esai atau nilai akhir siswa
  • Menggantikan penilaian akademik guru
Mesin analisis deterministik: rata-rata, nilai tertinggi/terendah, tingkat penguasaan, kehadiran, tugas terlewat, tren nilai — dihitung oleh logika aplikasi/database, bukan AI. AI hanya menjelaskan angkanya dalam bahasa natural.

8Excel, Impor & Mesin Dokumen

Excel adalah format kelas satu — input maupun output yang bisa diedit.

Impor: Upload → Read → Preview → Map Kolom → Validasi → Konfirmasi → Update DB Ekspor: DB → ExcelJS → XLSX terformat (header, freeze panes, filter, border, formula)

Tidak pernah impor langsung ke data produksi tanpa preview & validasi. File Excel yang diedit turunan tidak otomatis mengubah database — harus lewat siklus impor + konfirmasi guru.

Desain template selalu dipisahkan dari data inti — template bukan sumber kebenaran.

9File Storage

File biner besar tidak disimpan di PostgreSQL. Database menyimpan metadata, penyedia storage menyimpan file fisik — lewat abstraksi StorageService:

upload()download()delete()getUrl() (presigned)

Implementasi produksi: S3-compatible (AWS SDK v3 + presigned post). Development bisa pakai implementasi sederhana; provider bisa diganti tanpa menulis ulang modul bisnis.

Catatan serverless: dengan Prisma 7 + driver pg di Vercel, wajib pakai Neon pooled connection string agar koneksi DB tidak bocor saat ujian serentak. Env wajib di server: DATABASE_URL, BETTER_AUTH_SECRET, BETTER_AUTH_URL (harus = domain produksi), PIN_PEPPER (harus konsisten, kalau beda semua PIN siswa invalid), kunci AI, kunci storage.

13Prinsip Arsitektur Non-Negotiable (V1)

  1. Modular Monolith — tidak ada microservices.
  2. PostgreSQL adalah sumber kebenaran inti.
  3. Perubahan database wajib lewat Prisma migrations.
  4. Konteks akademik bersifat opsional.
  5. Rencana mengajar ≠ pelaksanaan mengajar.
  6. Aktivitas menghasilkan data; laporan di-generate dari data inti.
  7. Excel adalah format impor/ekspor kelas satu.
  8. AI selalu di balik abstraksi AI Service.
  9. Perhitungan deterministik tidak bergantung pada AI.
  10. AI tidak pernah menentukan nilai siswa di V1.
  11. Komponen reusable di atas UI duplikat.
  12. Stage yang sudah lulus tidak boleh dirusak stage berikutnya.
  13. Keep V1 simple — infrastruktur tambahan hanya saat ada kebutuhan nyata.
