Klassa Agent: Asisten Guru & Konsultan Ber-Data

Spesifikasi arsitektur produk, skema basis data, dan peta jalan implementasi agen cerdas portal guru dalam ekosistem Klassa OS.

1. Ringkasan 2. Keputusan Produk 3. Arsitektur Teknis 4. Alur Konfirmasi 5. Klassa Pulse 6. Peta Jalan Sprint
📖 1. Ringkasan Eksekutif

Klassa Agent adalah kepanjangan tangan guru di seluruh portal Klassa OS. Berbeda dari AI generik yang buta terhadap data ruang kelas, agen ini terhubung langsung ke basis data rombel (profil murid, rekap nilai asesmen, riwayat kehadiran, kuis, dan pemantauan perilaku).

📊 1. Admin Ber-Data
Membaca, menghitung statistik, dan menyajikan laporan profil siswa serta tren akademik dalam bahasa alami.
💡 2. Rekan Pedagogi
Teman diskusi solutif memecahkan masalah siswa pasif/kesulitan belajar tanpa memberi diagnosis medis/klinis.
⚡ 3. Operator Kelas
Membantu mengeksekusi absensi, kuis, nilai, RPP, dan pengumuman wali murid dengan input minimal dari guru.
🛡️ 2. Keputusan Produk Utama (Locked)
🔀 Universal Multi-Model (Bebas LLM Apa Saja)
Agen 100% bebas vendor lock-in. Model seperti Gemini, Claude, GPT-4o, DeepSeek, atau Hermes/Ollama hanyalah contoh. Sistem bebas dipasangi LLM apa saja via protokol standar (OpenAI-compatible, vLLM, Groq, model lokal/custom) tanpa merombak tools.
🧠 Memori Komprehensif (Rangkuman Umum)
Bukan hanya preferensi kaku. Mesin perangkum otomatis membaca dan merangkum inti pembahasan chat guru secara umum (proyek ajar berjalan, kendala unik siswa, ide kelas) agar agen selalu terhubung dengan perjalanan mengajar sang guru.
🔢 Kalkulasi Deterministik (Semua Hal)
LLM dilarang berhitung mandiri. Semua hal di Klassa yang bisa dikalkulasi (nilai rata-rata, persentase absen, jumlah submit tugas, ranking kelas, durasi kuis, remedial, audit kuota) dihitung 100% presisi oleh kode program Next.js.
🔒 Isolasi Hak Akses (Scope B2)
Pagar ketat di level fungsi kode (isPengampuRombel). Guru hanya dapat mengakses siswa dari rombel yang dia ampu. Akses kelas lain ditolak keras secara otomatis.
🎯 Kebijakan Ruang Lingkup Topik Guru
• Pertanyaan Pendidikan di Luar Kelas: Dilayani & didukung 100% (Kurikulum Merdeka, sertifikasi PMM, pedagogi umum, materi rapat). Agen bertindak sebagai rekan diskusi profesi guru.
• Pertanyaan Non-Pendidikan (Luar Konteks): Ditolak secara halus dan santun (polite deflection) dan diarahkan kembali ke persiapan kelas demi menjaga profesionalisme & menghemat kuota token.

Matriks Aksi: Otomatis vs Wajib Konfirmasi

Tingkat Risiko Cakupan Tindakan Contoh Aksi di Klassa Perilaku Agen
Aksi Hijau (Aman) Membaca data, kalkulasi statistik, penyusunan draf teks Query absensi, rekap nilai siswa, draf modul ajar RPP, draf pesan santun wali Langsung dieksekusi tanpa konfirmasi tambahan
Aksi Kuning/Merah (Sensitif) Menulis database resmi, publikasi materi, mutasi data permanen Simpan presensi resmi, input nilai rapor, rilis kuis baru, broadcast pengumuman WAJIB Konfirmasi Eksplisit via kartu interaktif di bubble chat
🏗️ 3. Arsitektur Teknis & Skema Database

Model Prisma baru untuk mencatat riwayat percakapan, proposal aksi berisiko, preferensi ingatan guru, serta data analitik makro: 

// 1. Sesi Percakapan Guru
model AgentConversation {
  id               String         @id @default(cuid())
  teacherProfileId String
  teacherProfile   TeacherProfile @relation(fields: [teacherProfileId], references: [id], onDelete: Cascade)
  title            String         @default("Percakapan Baru")
  modelUsed        String         @default("gemini-1.5-flash")
  classContextId   String?
  createdAt        DateTime       @default(now())
  updatedAt        DateTime       @updatedAt
  messages         AgentMessage[]
  @@map("agent_conversation")
}

// 2. Pesan & Proposal Aksi Interaktif
model AgentMessage {
  id             String            @id @default(cuid())
  conversationId String
  conversation   AgentConversation @relation(fields: [conversationId], references: [id], onDelete: Cascade)
  role           String            // 'user' | 'assistant' | 'system' | 'tool'
  content        String            @db.Text
  toolCalls      Json?
  toolResults    Json?
  pendingAction  Json?             // Usulan aksi berisiko tinggi
  actionStatus   String?           // 'NONE' | 'PENDING' | 'CONFIRMED' | 'REJECTED'
  createdAt      DateTime          @default(now())
  @@map("agent_message")
}

// 3. Memori Preferensi Jangka Panjang Guru
model TeacherAgentMemory {
  id                String         @id @default(cuid())
  teacherProfileId  String         @unique
  teacherProfile    TeacherProfile @relation(fields: [teacherProfileId], references: [id], onDelete: Cascade)
  communicationTone String         @default("RAMAH_SOPAN")
  preferredModel    String         @default("gemini-1.5-flash")
  pedagogyDefaults  Json?          // Format RPP andalan, model belajar favorit
  customContext     String?        @db.Text
  updatedAt         DateTime       @updatedAt
  @@map("teacher_agent_memory")
}

// 4. Agregasi Analitik Makro (Klassa Pulse - Tanpa PII)
model AgentInsightAggregate {
  id             String   @id @default(cuid())
  date           DateTime @db.Date
  topicCategory  String   // 'KEDISIPLINAN' | 'LITERASI' | 'METODE_AJAR' | 'MOTIVASI'
  subjectGroup   String?  // 'MATEMATIKA' | 'IPA' | 'BAHASA'
  gradeLevel     String?  // 'SD' | 'SMP' | 'SMA'
  regionCode     String?
  sentimentScore String   // 'POSITIF' | 'NETRAL' | 'KEWALAHAN_STRES'
  frequency      Int      @default(1)
  activeHour     Int      // 0 - 23 (Jam aktivitas)
  createdAt      DateTime @default(now())
  @@map("agent_insight_aggregate")
}
💬 4. Simulasi UI: Kartu Konfirmasi Aksi (Human-in-the-Loop)

Ketika guru menginstruksikan aksi berisiko (misal catat absensi), agen menyusun parameter secara deterministik dan menampilkan kartu persetujuan:

Guru:
"Tolong catat presensi kelas 8-B hari ini. Semua masuk, cuma Rizky yang izin dan Doni sakit."
Klassa Agent:
Siap Pak! Saya sudah memeriksa rombel 8-B dan menyiapkan draf pencatatan presensi hari ini. Silakan periksa rinciannya sebelum saya simpan ke database resmi sekolah:
📋 Usulan Presensi Resmi: Kelas 8-B ⚠️ Menunggu Persetujuan Guru
• Hadir: 30 Siswa
• Izin: 1 Siswa (Rizky Pratama)
• Sakit: 1 Siswa (Doni Kurniawan)

🚀 6. Peta Jalan Eksekusi (Sprint Roadmap)
Story 1: Fondasi Agent Runtime & Multi-Model
Instalasi Vercel AI SDK, migrasi tabel skema percakapan di Prisma, router multi-model dinamis, dan UI obrolan dasar dengan streaming.
Story 2: Memory Store & Tools Query Data Kelas
Layanan memori preferensi guru, tools pembaca data siswa/absen/nilai deterministik, dan pagar mutlak otorisasi isPengampuRombel.
Story 3: Skill Pedagogi & Pagar Keamanan Psikologis
System prompt pedagogi Kurikulum Merdeka, deteksi penolakan diagnosis medis anak, dan penyensoran token audit log (redactMetadata).
Story 4: Action Mutation & Kartu Konfirmasi Interaktif
Komponen kartu interaktif bubble chat, tools mutasi data (absen, kuis, pengumuman), dan penyimpanan draf ke AI Studio.
Story 5: Polish, Floating Widget & Settings
Widget terapung di dashboard guru, menu pengaturan gaya bahasa/reset memori agen, dan panduan konfigurasi model mandiri (Hermes/vLLM).
Story 6: Admin Console — Klassa Pulse Insights
Pipa ekstraksi topik teranonimkan di latar belakang dan dashboard visualisasi interaktif isu guru Indonesia menggunakan Recharts.
