✅ Keputusan Terkunci

Yang diputuskan

  • 🎯Scope V1 — file untuk jawaban siswa saja; lampiran guru menyusul.
  • 📦Semua jenis file diterima kecuali program & makro (.exe, .apk, .bat, .docm, dll) — bukan kurir virus.
  • 👁️Pratinjau bertingkat — foto & PDF inline; Word/PPT/video/ZIP jadi tombol unduh dengan nama asli.
  • 📏Limit — maks 25 MB per file, maks 5 file per pengumpulan.
  • 🗄️Storage S3-compatible — Cloudflare R2 sekarang; MinIO di server sendiri nanti, pindah via env tanpa ubah kode.
  • 🚀Upload langsung browser → storage (presigned URL); file tidak lewat server Next.js.
  • 🔒Privat — siswa hanya file miliknya; guru hanya rombelnya; unduh via route terautentikasi.
  • 🗑️Resubmit sebelum dinilai — file lama dihapus, diganti baru, tanpa arsip.
  • 🏷️Penamaan — nama internal acak; nama asli jadi metadata tampilan.
  • 📎Lampiran guru (Story 2) — file soal/LKPD di level tugas; limit sama (25 MB, 5 file); bebas diubah kapan saja; seluruh siswa rombel boleh akses.
  • 🧱Eksekusi berurutan — Story 1: infra + jawaban siswa → Story 2: lampiran guru; skema DB sekalian.
❌ Ditolak

Yang dibuang & alasannya

  • 🚫Vercel Blob — API proprietary, pindah server = tulis ulang kode, kena biaya tiap foto dibuka.
  • 🚫Allowlist ketat (foto+PDF saja) — terlalu kaku; diganti blocklist yang lebih luas namun tetap aman.
  • 🚫Limit 10 MB / 3 file — proposal awal; dinaikkan ke 25 MB / 5 file karena jenis file dibebaskan.
  • 🚫Simpan file lama saat resubmit — diputuskan hapus, demi storage bersih.
