## Story 1a — Fondasi Skema & Migrasi

| # | Severity | Temuan | Perbaikan Diterapkan |
|---|----------|--------|----------------------|
| F1 | 🔴 | **`AuditLog` tanpa `@id` → schema INVALID.** Task memerintahkan "persis sesuai Design Notes" yang tak mencantumkan PK; Prisma mewajibkan `@id` (30 model lain punya). Implementer patuh → `prisma validate` FAIL → door criteria mati. | Design Notes: + `id String @id @default(cuid())` |
| F2 | 🔴 | **Tanpa `@@map` → tabel `"AuditLog"` CamelCase.** Seluruh 30 tabel repo snake_case; retrofit kemudian = migrasi RENAME (melanggar semangat aditif N1). | Design Notes: + `@@map("audit_log")` |
| F3 | 🟡 | **AC#2 tak bisa dieksekusi dalam scope 1a** — Prisma client otomatis meng-expose update/delete; 1a (Never) menolak menulis kode aplikasi. | AC#2 direword: verifikasi schema valid + nol service update/delete; penegakan di 1c/Story 3+ |
| F4 | 🟡 | Verification tanpa `prisma generate` — konsumen kolom baru (1b/1c/Story 3+, CI) butuh client regen eksplisit. | Verification: + `npx prisma generate` (idempotent) |
| F5 | 🔵 | Typo frozen 1c: "`migrate migrate deploy`". | Diperbaiki di 1c (+ tercatat di SCL 1c) |

**Yang bertahan:** fidelitas pecahan (7 baris matriks PIN utuh di 1b, 6 baris seeder di 1c, manual check `platformRole` berpindah ke 1c dengan benar); line number Code Map eksak; migrasi aditif aman (ADD COLUMN DEFAULT = metadata-only PG 11+; unique index di atas NULL = instan); ordering 1a → 1b paralel → 1c bersih.

## Story 1b — Primitif PIN (scrypt + pepper)

| # | Severity | Temuan | Perbaikan Diterapkan |
|---|----------|--------|----------------------|
| B1 | 🟡 | **Opsi pengerasan pepper (`NODE_ENV === "development"` saja) mematikan test suite** — vitest men-set `NODE_ENV=test` → fail-fast module-load menyala di tengah test run. | Opsi diperbaiki: fallback aktif bila `NODE_ENV ∈ {development, test}` |
| B2 | 🟡 | **Sync vs async scrypt tak dispesifikasi** — `scryptSync` memblokir event loop ±50ms (N=16384) per verify; fatal di hot-path login Story 3 under load. | + Kontrak: `crypto.scrypt` promisified (bukan `scryptSync`) |

**Yang bertahan:** 7 baris matriks PIN utuh dari Story 1; referensi `auth.security.test.ts` ada; tidak ada modul mengimpor `student-pin.ts` (klaim "boot aman" valid); `maxmem` 64 MB vs kebutuhan 16 MB = headroom 4×.

## Story 1c — Allowlist & Seeder Superadmin

| # | Severity | Temuan | Perbaikan Diterapkan |
|---|----------|--------|----------------------|
| C1 | 🔴 | **Seeder tidak akan pernah melihat `.env`** — `tsx` tidak memuat `.env` otomatis; repo tanpa dotenv (terverifikasi: nol kemunculan di package.json/scripts). `npm run seed:superadmin` selalu fail-fast "allowlist kosong" walau `.env` terisi; `DATABASE_URL` pun tak terbaca Pool. | Script → `tsx --env-file-if-exists=.env scripts/seed-superadmin.ts` (Node ≥22.9 ✓ v22.23.2; varian `-if-exists` aman di CI tanpa .env) — Code Map + Task |
| C2 | 🟡 | **CLI hang tanpa shutdown eksplisit** — pg Pool menjaga event loop hidup; script "selesai" tanpa exit → CI timeout. | + Design Notes: `await pool.end()` (+ `prisma.$disconnect()`) + `process.exit(code)`; audit hanya ditulis saat perubahan state nyata (no-op re-run = nol entri) |
| F5 | 🔵 | Typo frozen Never (lintas story dari 1a). | "`migrate migrate deploy`" → "`prisma migrate deploy`" + entri SCL |

**Yang bertahan:** 6 baris matriks seeder utuh; prasyarat 1a eksplisit; `actorType="SYSTEM"` + metadata bebas secret selaras Design Notes 1a; idempotency terdefinisi di matriks.
